# 선수 팀 GP FGA 실제 기대(xPts) 델타 ▾
xPts(기대득점)란 - 15시즌 전체 리그 평균 기준, 그 슛이 던져진 코트 위치(구역)에서 평균적으로 얼마나 성공하는지를 근거로 "이 슛 하나가 평균적으로 몇 점짜리인가"를 계산한 값 (build_xpts_shot_quality.py). 최근 5경기 동안 던진 모든 슛(성공+실패)의 xPts를 더한 게 "기대득점", 실제로 넣은 슛만 점수로 환산해 더한 게 "실제". 이 둘의 차이가 "슛 난이도로는 설명 안 되는, 지금 이 선수의 결정력/컨디션"에 가까운 신호.
2025-2026 시즌 기준 · 선수별 최근 5경기 롤링 윈도우 · xPts 존 테이블은 15시즌(2011-12~2025-26) 전체 평균.
